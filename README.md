VERSA Portfolio

A modern full-stack portfolio platform built to showcase projects, skills, experience, and professional work.

🚀 About the Project

VERSA Portfolio is a full-stack web application designed to provide a professional and interactive portfolio experience.

The project includes a modern frontend, backend services, database integration, authentication, project management, and an admin system.

Frontend

- JavaScript
- HTML5
- CSS3
- Responsive Design

Backend

- Node.js
- Express.js
- MongoDB
- REST API
- JWT Authentication

Tools & Services

- API Integration

✨ Features

- Professional portfolio website

- Project details and galleries

⚙️ Installation

Clone the repository:

git clone https://github.com/sayedmadain887-dev/VERSA-Portfoilo.git

Install dependencies for each project:

cd frontend
npm install

Then install the backend dependencies:

cd ../backend
npm install

Configure the required environment variables in your local ".env" files.

▶️ Running the Project

Start the frontend:

npm run dev

Start the backend:

npm run dev
